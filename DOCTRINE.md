# ✦ SHINY DOCTRINE

## The Central Truth

**Shiny design is not about covering a thing in gloss. It is about deciding where brilliance lives.**

Brilliance may live in:
- **veins**
- **seams**
- **cracks**
- **tessellated edges**
- **woven light-paths**
- **buried channels**
- **reflective dust ecologies**
- **pressure bands**
- **contour ridges**
- **kintsugi sutures**
- **prismatic boundaries**
- **luminous structural filaments**

## The Host/Active Contrast Rule

The best shiny design usually contrasts:
- a **quiet host material** against
- a **highly active optical subsystem**

The host is:
- absorbent
- soft
- dry
- deadened
- low specular
- stable

The optical subsystem is:
- reflective
- wet-looking
- luminous
- active
- precious
- dynamic

## Shine Hierarchy (Layer It)

Don't make all shine the same size or behavior. Make a hierarchy:

| Layer | Behavior | Examples |
|-------|----------|----------|
| **1** | broad soft sheen | pearl / oil / satin / latex |
| **2** | medium directional shine | chrome streaks / woven seams / foil folds |
| **3** | tiny sparkle events | glitter / sequins / microglints |
| **4** | rare explosive highlights | starbursts / mirror flashes / jewel pings |

That is how you get *expensive*.

## Material Logic Questions

Before adding shine, answer:
1. What part of the object is **carrying** the shine?
2. What **material logic** decides where shine lives?
3. Is the shine skin-deep, embedded, wet, crystalline, metallic, prismatic, electric, oily, glittery, holographic, mirror-like?

## Shine Behaviors

Shine can behave like:
- **pulsing** — heartbeat, signal, pump
- **branching** — veins, roots, cracks, rivers
- **crawling** — infection, mold, residue
- **pooling** — oil, lacquer, wet accumulation
- **fraying** — worn edges, torn foil, degraded glitter
- **woven** — over/under, textile, basketweave
- **sutured** — stitches, repair, scar tissue
- **leaking** — buried shine breaking through
- **blooming** — mold, pollen, spores, growth
- **flaring** — sudden glints, starbursts, overload
- **smearing** — wet drag, oil slick, lip gloss
- **flickering** — nervous system, signal, unstable
- **rippling** — caustics, water, pressure waves
- **banding** — stress, birefringence, contours
- **clustering** — ecology, neighborhoods, density
- **crystallizing** — frost, growth, mineral formation
- **refracting** — prism, caustic, spectral split
- **tearing** — foil, paper, edge shine
- **sparkling** — glitter, sequins, microflakes
- **ghosting** — buried, subsurface, faint, hidden
