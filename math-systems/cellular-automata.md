# Cellular Automata for Shine

## What
Grid-based rules for growth, decay, and pattern formation.

## Use For
- Mold / moss growth
- Infection spread
- Crystal formation
- Residue patterns
- Chrome colonization

## Rules
- **Conway's Life**: birth/survival thresholds
- **Cyclic CA**: color cycling, spiral waves
- **Lenia**: continuous CA, organic blobs
- **Reaction-diffusion CA**: Gray-Scott on grid

## Shine Adaptation
- Alive cells = mold body / infection
- State transitions = growth front
- Dead cells = matte host
- Boundary = active shine zone
