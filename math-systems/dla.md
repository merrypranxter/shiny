# DLA (Diffusion-Limited Aggregation) for Shine

## What
Random walkers that stick to a growing cluster — fractal branching.

## Use For
- Organic vein networks
- Crystal growth
- Lightning / discharge patterns
- Coral / branching structures
- Mold colony edges

## Algorithm
1. Seed cluster at center
2. Launch random walker from edge
3. If walker touches cluster, stick and become part of cluster
4. Repeat

## Shine Adaptation
- Cluster = matte host + shiny edges
- Growth front = active sparkle zone
- Branch tips = terminal glints
- Density = thickness / opacity
