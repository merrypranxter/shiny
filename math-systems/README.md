# ✦ MATH SYSTEMS FOR SHINE DESIGN

Reference documentation for the generative math behind shiny effects.

## Systems by Shine Type

### For veins / channels / branching shine
- L-systems
- slime mold network logic
- DLA (diffusion-limited aggregation)
- reaction-diffusion skeleton extraction
- gradient-flow tracing
- shortest-path / medial-axis networks

### For woven light / pattern light
- tessellations
- Penrose tilings
- Voronoi / Delaunay
- Islamic geometry
- braid / weave over-under rules
- graph-based edge lighting

### For cracks / seams / repair shine
- Voronoi fracture
- recursive subdivision
- crack propagation fields
- stress maps
- contour ridges

### For clustered glitter / mirror-dust shine
- fBm masks
- multifractals
- blue-noise sampling
- clustered Poisson-ish fields
- scale-nested density fields

### For embedded optical color
- thin-film interference approximation
- structural color / Voronoi cell pockets
- fresnel fields
- birefringence / stress-band mapping
- chromatic edge offsets

### For weather / contour / field shine
- fBm pressure fields
- contour bands
- flow fields
- particle advection
- thresholded cloud maps
- curl noise-ish motion

### For infrastructure / network shine
- graph networks
- route maps
- nearest-neighbor graphs
- circuit traces
- minimum spanning trees
- recursive city grids
- Hilbert curves / space-filling paths
