# Slime Mold for Shine

## What
Physarum polycephalum simulation — nature's network optimizer.

## Use For
- Optimal vein routing
- Network infrastructure
- Nutrient / signal paths
- Organic circuit design
- Living shine systems

## Algorithm (Particle-based)
1. Particles move, sense trail ahead
2. Deposit pheromone / trail
3. Trail decays and diffuses
4. Network optimizes over time

## Shine Adaptation
- Trail network = vein system
- High-trail areas = bright conduits
- Nodes = junction glints
- Decay = fading shine
