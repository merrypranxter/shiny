# ✦ System 29: SONIC SHINE

## Core Idea

Sound waves are pressure waves. Pressure affects refractive index. Refractive index affects light. Therefore: **sound can create visible optical patterns**.

Usually this is invisible (Schlieren photography captures it). Instead: **amplify and aestheticize the optical effects of sound**.

## Concept

**Light passing through sound fields** — the sound creates density gradients that bend, split, and color light.

- Standing wave: nodes = clear, antinodes = colored
- Chladni patterns: sand on plate, but with light instead
- Beat frequencies: interference between two sound sources = moiré-like optical beats
- Doppler shift: moving sound sources = color shift in passing light

The result: a **visible sound field** — light that carries the shape of acoustic energy.

## Math Systems

| Component | Math | Purpose |
|-----------|------|---------|
| Sound field | Wave equation + boundary conditions | pressure distribution |
| Refractive index | n = n₀ + k * pressure | optical response |
| Light propagation | Ray tracing through varying n | caustics/refraction |
| Color | Phase delay * frequency | chromatic output |

## Code Hook (GLSL)

```glsl
vec3 sonicShine(vec2 uv, float t, float freq1, float freq2) {
  // Standing wave field
  float pressure = sin(uv.x * freq1 + t) * sin(uv.y * freq2);

  // Refractive index variation
  float n = 1.0 + pressure * 0.1;

  // Light ray bending
  vec2 bend = vec2(dFdx(n), dFdy(n)) * 2.0;

  // Chromatic separation (different bend per wavelength)
  float bendR = length(bend) * 1.0;
  float bendG = length(bend) * 0.95;
  float bendB = length(bend) * 0.9;

  // Sample displaced coordinates
  vec3 color;
  color.r = texture2D(source, uv + bend * bendR).r;
  color.g = texture2D(source, uv + bend * bendG).g;
  color.b = texture2D(source, uv + bend * bendB).b;

  return color * (1.0 + pressure * 0.5);
}
```

## Variants

- **Sonic anatomy**: body where heartbeat creates standing wave optics in flesh
- **Sonic weather**: storm where thunder creates shockwave light patterns
- **Sonic instrument**: musical instrument where notes = color patterns
- **Sonic architecture**: room where acoustic modes = permanent light sculptures
- **Sonic conversation**: speech that leaves colored pressure trails in air

## Why It Works

Sound is **invisible energy**. Making it visible through light creates a **synesthetic experience** — the viewer sees what they should only hear. The connection between acoustic physics and optics is real but rarely aestheticized. This system makes sound **tangible, colorful, spatial**.
