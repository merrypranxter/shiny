# ✦ System 27: POLARIZATION TOPOGRAPHY

## Core Idea

Polarized light carries orientation information. Crossed polarizers block light — but birefringent materials rotate polarization, creating color [^50^]. Usually used for stress analysis. Instead: **build aesthetic topographies from polarization rotation**.

The color isn't painted on. It's generated by the material's optical response to polarized light. The topography IS the polarizer.

## Concept

**Surfaces where elevation, slope, and curvature control polarization rotation** — and therefore color.

- Flat areas: no rotation = dark (crossed polarizers)
- Slopes: partial rotation = grayscale
- Curved ridges: full rotation = rainbow
- Sharp peaks: over-rotation = complementary colors

The result: a topographic map that is also a **polarization interferogram**. Move the polarizers: the map changes color.

## Math Systems

| Component | Math | Purpose |
|-----------|------|---------|
| Surface | fBm terrain | height field |
| Stress field | Curvature + slope | birefringence proxy |
| Polarization rotation | Stress * thickness | phase delay |
| Color | Interference of rotated components | visual output |

## Code Hook (GLSL)

```glsl
vec3 polarizationMap(vec2 uv, float polarizerAngle) {
  // Terrain height
  float h = fbm(uv * 3.0);

  // Curvature as stress proxy
  vec2 dh = vec2(dFdx(h), dFdy(h));
  float curvature = length(dh);

  // Thickness varies with height
  float thickness = 1.0 + h * 2.0;

  // Phase delay = stress * thickness
  float phase = curvature * thickness * 10.0;

  // Polarized light through crossed polarizers
  float polAngle = polarizerAngle + phase;
  float transmission = pow(sin(polAngle), 2.0);

  // Birefringence color
  vec3 color = vec3(
    0.5 + 0.5 * cos(phase + 0.0),
    0.5 + 0.5 * cos(phase + 2.1),
    0.5 + 0.5 * cos(phase + 4.2)
  );

  return color * transmission;
}
```

Polarization is **invisible physics made visible**. Most people have never seen birefringence — when they do, it's mesmerizing. By tying it to topography, you give the color a **spatial logic** that the viewer can read. It's a map and a light show simultaneously.
