# ✦ CODE SNIPPETS

Extracted code patterns from the system docs, ready to drop into projects.

## Structure

Each `.js` file contains the core generative pattern for that system:
- Vein generators (L-systems, DLA, flow fields)
- Tessellation renderers (Voronoi, Penrose, Delaunay)
- Crack systems (propagation, fracture, stress maps)
- Buried shine (subsurface, SDF, fresnel)
- Glitter ecology (blue noise, Poisson, clustering)
- Metallic palettes (gradient maps, chrome logic)
- Weather systems (contour extraction, fBm fields)
- Infrastructure networks (graph, MST, shortest path)
- Embroidery stitches (Hilbert curves, braids)
- Wet/dry shine (state machines, material switching)
- Anatomy systems (L-systems, reaction-diffusion skeletons)
- Repair/damage (Voronoi fracture, kintsugi fill)
- Woven structures (weave rules, over-under logic)
- Residue/contamination (cellular automata, slime mold)
- Language/symbols (SDF glyphs, sigil generation)
- Object logic (shape grammars, recursive forms)
- Costume/fashion (drape simulation, attachment rules)
- Map/topography (contour bands, elevation shine)
- Caustic projection (warped domain, recursive distortion)
- Metallic sculpture (gradient flow, chrome surfaces)

## Usage

```javascript
import { veinNetwork } from './vein-generators.js';
import { voronoiCells } from './tessellation-renderers.js';

const veins = veinNetwork({ iterations: 5, angle: 25 });
const cells = voronoiCells({ count: 100, width: 800, height: 600 });
```
