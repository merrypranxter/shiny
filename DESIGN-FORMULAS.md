# ✦ DESIGN FORMULAS

## Quick Generators

These are useful as invention engines. Plug in variables and generate concepts.

---

### Formula 1: [Dull Host Material] + [Branching Shiny System]

**Pattern:** A quiet surface interrupted by veins of optical violence.

**Examples:**
- velvet + opal veins
- chalk + glitter capillaries
- ceramic + chrome sutures
- stone + molten metallic seams
- matte latex + chrome nerves

**Math systems:** L-systems, reaction-diffusion skeletons, flow-field tracing, DLA, Voronoi seams

---

### Formula 2: [Tessellated Geometry] + [Shine Medium] + [Wrong Physical Behavior]

**Pattern:** A pattern made of light, but the light behaves impossibly.

**Examples:**
- Penrose tiling + fiber-optic thread + leaks color like sap
- Voronoi cells + rhinestones + pulse like a nervous system
- hex grid + holographic grout + liquefies at intersections
- Islamic star pattern + holographic tubing + breathes

**Math systems:** tessellations, Penrose tilings, Voronoi/Delaunay, Islamic geometry, braid rules

---

### Formula 3: [Fracture / Seam Logic] + [Luxury Optical Material]

**Pattern:** Damage becomes the most precious part.

**Examples:**
- crack map + pearl glaze
- kintsugi seams + diffraction film
- pressure ridges + polarized acrylic rainbow
- scar tissue + iridescent varnish
- fault lines + glitter resin

**Math systems:** Voronoi fracture, recursive crack propagation, stress maps, contour ridges

---

### Formula 4: [Soft Matte Body] + [Buried Luminous Structure]

**Pattern:** Shine lives underneath, visible but obscured.

**Examples:**
- silicone flesh + glitter veins
- chalk foam + opal skeleton
- plaster tile + woven chromatic wireframe underneath
- milky plastic + buried opal circuitry
- wax + chrome fossils

**Math systems:** embedded networks, lattice structures, contour lines, sealed seams, glitter organelles
