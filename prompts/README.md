# ✦ PROMPTS

Ready-to-use prompt formulas for generative pipelines.

## Formula 1: Host + Veins
```
[dull host material] with [branching shiny system], 
[optical material] veins, [behavior], [render style]
```
Example: `velvet surface with opal vein network, pulse glow, octane render`

## Formula 2: Tessellation + Shine
```
[tessellated geometry] made of [shine medium], 
[wrong behavior], [material quality]
```
Example: `Penrose tiling made of fiber-optic thread, leaks color like sap, translucent`

## Formula 3: Fracture + Luxury
```
[fracture logic] filled with [luxury optical material], 
[scale], [context]
```
Example: `crack propagation map filled with pearl glaze, macro, ceramic sculpture`

## Formula 4: Soft Body + Buried Light
```
[soft matte body] with [buried luminous structure], 
[visibility], [interaction]
```
Example: `silicone flesh with glitter vein skeleton, subsurface scattering, touch-reactive`
